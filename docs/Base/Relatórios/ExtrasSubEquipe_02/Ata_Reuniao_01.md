- O uso de inteligência artificial deve ser documentado de maneira mais crítica e detalhada, incluindo:
  - Capturas de tela;

- Houve uma discussão sobre a utilização do Figma, mas não foi identificada uma conclusão clara de que a ferramenta tenha sido diretamente criticada pela professora.

### 3.2. Definição dos Artefatos da Segunda Entrega

Foi explicado que a segunda entrega deveria conter dois modelos:

- Um modelo de **modelagem estática**;
- Um modelo de **modelagem dinâmica**.

As opções discutidas foram:

| Modelagem | Opções |
|---|---|
| **Estática** | Diagrama de classes, pacotes ou componentes |
| **Dinâmica** | Diagrama de sequência, colaboração, atividades ou estados |

O subgrupo 1 aparentemente havia escolhido:

- Diagrama de componentes para a modelagem estática;
- Diagrama de sequência para a modelagem dinâmica.

Dessa forma, foi discutida a possibilidade de utilizar:

- **Diagrama de pacotes** para a modelagem estática;
- **Diagrama de atividades** para a modelagem dinâmica.

Essa escolha permitiria trabalhar com artefatos diferentes dos selecionados pelo subgrupo 1.

### 3.3. Sistema Analisado

Foi discutida a possibilidade de trocar o sistema analisado. Entretanto, os integrantes decidiram manter o **Informa.br**, considerando a familiaridade adquirida durante a entrega anterior.

Também foi discutida a possibilidade de manter o mesmo repositório e adicionar os novos artefatos ao projeto já existente.

### 3.4. Organização das Atividades

Inicialmente, foi considerada a divisão das tarefas entre os integrantes, com posterior revisão mútua.

Em seguida, foi proposta uma abordagem na qual cada integrante produziria sua própria versão dos diagramas, permitindo uma comparação posterior.

Ao final da discussão, houve concordância com a seguinte organização:

- Cada integrante produzirá uma versão do diagrama de pacotes;
- Cada integrante produzirá uma versão do diagrama de atividades;
- As versões serão comparadas posteriormente;
- O grupo escolherá ou consolidará uma versão definitiva;
- As diferenças e justificativas das escolhas deverão ser documentadas.
